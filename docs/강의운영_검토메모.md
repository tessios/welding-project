## 2. 배포 전 원문 대조가 필요한 항목 `[확인 필요]`

- **조항 번호**: Table 5.1(와이어 지름), Table 5.7(차폐가스), Table 6.1(자세), Table 6.2(두께·필렛 주석), 7.21.1(루트 간격), 풍속 기준(약 8 km/h, 2.2 m/s).
- **Table 5.8 적용 근거**: SM275는 Group이 없어 Group I·II에 준해 참고 적용한 것. 실제 기준은 **PQR-ST-012의 예열값**이어야 함.
- **EOR(설계 책임자) 승인 경로**: D1.1 본문에 “등재되지 않은 강재를 승인으로 사전인정”하는 조항이 있는지. 근거가 없으면 “부분 점수” 표현은 빼야 함.
- **전류·가스 유량**: 실제 사용 와이어의 제조사 데이터시트 값으로 교체 권장.
- 참고: 검토에 쓴 Table 6.5 변동폭(전류 ±10 %, 전압 ±7 %, 속도 ±25 %, 예열 15 °C 이상 감소 불가)도 원문 대조 대상.

## 3. 수강생이 물을 만한 질문 5개 (30초 답변)

**Q1. SM275가 A36보다 항복강도가 높은데 왜 사전인정이 안 되나요?**
사전인정은 강도가 아니라 **목록**으로 판정합니다. Table 5.3은 AWS가 실적으로 검증한 규격만 올려 둔 표입니다. SM275는 성분·강도가 비슷해도 그 목록에 없습니다. “비슷하다”는 판단은 품질관리자가 아니라 시험(PQR)이나 설계 책임자가 해야 합니다.

**Q2. 예보가 −3 °C인데 모재가 해를 받아 0 °C를 넘으면 예열을 안 해도 되나요?**
규격상으로는 맞습니다. 기준은 기온이 아니라 **용접 직전 모재 온도**입니다. 다만 겨울 아침 철골은 기온보다 차갑고, WPS는 그날그날 바꾸는 문서가 아닙니다. 그래서 “최소 20 °C”로 정해 두고 용접 지점에서 75 mm 이상 떨어진 곳을 온도 측정 크레용·접촉식 온도계로 확인하는 것이 실무입니다.

**Q3. 용접사가 3G 자격이면 3F 작업도 되고, WPS도 3G면 3F가 되나요?**
둘은 다릅니다. **용접사** 3G 자격은 수직을 포함한 여러 자세의 필렛을 인정합니다. **WPS(PQR)** 는 시험한 자세만 인정해서 3G는 수직 그루브·수직 필렛만 됩니다. 오늘 사례는 둘 다 수직이라 맞아떨어진 것입니다.

**Q4. 회사에 맞는 PQR이 없으면 내일 작업은 못 하나요?**
원칙적으로는 못 합니다. PQR은 시편 용접 하루 + 기계시험·검사 며칠이 걸립니다. 할 수 있는 일은 ① 설계 책임자에게 강재 등가 인정을 서면 요청, ② 공정·부재를 바꿔 가능한 작업부터, ③ 일정에 PQR 시험을 바로 넣기. “일단 용접하고 서류는 나중에”는 감리 중지와 재작업으로 돌아옵니다.

**Q5. E71T-1C인데 현장에 Ar 혼합가스밖에 없으면 써도 되나요?**
와이어 포장에 **-1C/-1M 이중 분류**가 있으면 가능합니다. 그래도 PQR이 CO₂로 시험됐다면 가스 변경 자체가 필수변수 변경이라 WPS를 그대로 쓸 수 없습니다. C 단독 분류에 혼합가스를 쓰면 Mn·Si 회수율이 올라 강도·인성이 달라집니다. 가스는 **와이어 분류 + PQR** 두 곳을 다 봐야 합니다.

## 4. 90분 수업 진행안

- **목표**: 통화로 받은 부족한 정보를 규격 근거로 메워 D1.1 필렛 WPS를 완성하고, Prequalified와 Qualified를 판정한다.
- **준비**: 강사 화면 공유, 수강생 기기(URL·QR), 결과 캡처 제출 채널, 치명 오류 집계용 화이트보드.
- **사전 점검**: 공용 PC에서는 이전 작성값이 남을 수 있으므로 상단 `처음부터`로 초기화.

| 시간 | 단계 | 진행 | 강사 포인트 |
|---|---|---|---|
| 0–10 | 도입 | “WPS 없이 내일 용접하라면?” WPS·PQR·WPQ 관계 그림 | 정답 대신 문제의식만 |
| 10–20 | 미니 강의 | Clause 5(Prequalified) vs 6(Qualified), Table 5.3·5.4·5.8 위치 | “목록에 있는가”를 판정 기준으로 |
| 20–27 | 함께 보기 | 장면 1~3 시청, 끊긴 정보 4개를 학생이 말하게 | **자료함 3개는 언급하지 않음**(스스로 찾게) |
| 27–52 | 실습 1회차 | 작성 → 제출 → 결과 캡처 | 질문에는 “그 칸 팝오버 봤어요?”로 되묻기 |
| 52–57 | 집계 | 손들기로 치명 오류 Top 3 (보통 18번 인정방식, 15번 예열, 11번 필러) | 파단 유형별 공유 |
| 57–72 | 실습 2회차 | 2인 1조, 피드백 해석 후 재도전, 합격자는 근거 설명 | 자료함을 찾은 조가 힌트 제공 |
| 72–85 | 리뷰 | 정답 18칸 확인 + 토론 ① SM275와 Table 5.3 ② 기온과 모재 온도 ③ 3G PQR과 3F | Q1~Q3 사용 |
| 85–90 | 정리 | “익숙한 강재는 근거가 아니다.” 과제: 소속 현장 WPS 1장의 Prequalified 근거 확인 | Q4·Q5는 과제로 |

시간이 부족하면 미니 강의 5분·2회차 10분으로 줄이고, **리뷰는 줄이지 않습니다.**

## 5. 앱에서 아직 다루지 않은 항목(확장 후보)

용접 속도 범위, 팁-모재 거리(CTWD), 비드 기법(스트링어/위빙)·패스 수, 층간·패스 후 청소(슬래그 제거), 예열 측정 방법 — 현재는 각 칸 팝오버 설명으로만 일부 안내되어 있습니다. 칸을 늘리지 않고 기존 칸(와이어·자세·PWHT 옆)에 합치는 방식을 권장합니다.
