# WPS 실습실 — AWS D1.1 · Carbon Steel

탄소강 구조물(AWS D1.1) 기준으로 **WPS 한 장을 읽고 · 변수를 바꿔 보고 · 직접 작성해 채점받는** 강의용 정적 웹앱입니다.
서버·로그인이 없고, 모든 상태는 브라우저 `localStorage`에 저장됩니다.

> ⚠️ **교육용입니다.** 화면의 WPS·PQR·과제서는 모두 가상 문서이고, 수치는 판본 원문 대조 전 교육용 대표값입니다.
> 실제 제작·검사에는 계약에서 지정한 판본의 AWS D1.1 원문과 발주처 시방서를 적용하세요.

## 구성 (18분 5단계)

| 단계 | 화면 | 내용 |
|---|---|---|
| ① 이론 카드 | S1 | 사전인정(Clause 5) vs 시험인정(Clause 6), E/S/N 세 층 판단, Table 6.2·5.8, 12포인트 지도 |
| ② 독도 | S2 | 슬라이드 「1. WPS 보는법」의 **1–12번 순서** 그대로 클릭 → 조항 · 근거 풀이 · 현장 주의 · 확인 퀴즈. 가이드/자유/퀘스트 3모드 |
| ③ 시뮬레이터 | S3 | 계산기(강재→Group·예열 범주, 두께 인정범위, 자세 인정, 입열량) + 변경 시나리오 3문제(E/S/N·조치 판정) |
| ④ 작성 | S4 | 과제서 + 지원 PQR만 보고 10단계 마법사로 WPS 작성. 형식 검증 즉시 표시, 3단계 힌트(1단계 무료) |
| ⑤ 채점 | S5·S6 | 100점 환산 · 치명 오류 판정 · 12포인트 히트맵 · 오답 리뷰(근거 조항·독도 역링크) · 틀린 칸만 재시도 |

보조: 조항·용어 사전(오버레이, 검색), 강사 모드(결과 JSON·CSV 내보내기, 기록 초기화).
세션은 **전체 / 독도만 / 실습만**으로 나눠 진입할 수 있습니다.

## 기준 데이터

- **강종**: Carbon Steel — ASTM A36, A572 Gr.42/50/60/65, A992, A588, A709 Gr.50W/70W (A514는 사전인정 불가 예시)
- **기반 규격**: AWS D1.1/D1.1M:2020 (2025 개정 표 번호 병기)
  - Clause 5 사전인정: Table 5.2(필수변수) · Table 5.3(승인 모재 Group I–IV) · Figure 5.1–5.3(이음상세) · Table 5.7(차폐가스) · Table 5.8(최소 예열·층간)
  - Clause 6 시험인정: Table 6.1(자세 인정) · Table 6.2(CJP 두께 인정) · Table 6.6(필수변수 변경) · Table 6.7(CVN 보충)
  - 2025 Edition 대응: 5.5(필수변수) · 5.6(모재) · 5.11(예열) · 6.6/6.8
- **실습 소재**: FCAW-G · E71T-1(F6/A1) · CO2 · DCEP · B-U2a-S · A992 Gr.50 · 시험편 16 mm → 인정 두께 3–32 mm, 자세 F

## 파일

```

data.js      콘텐츠·참조 데이터(강재·용가재·예열표·12포인트·시나리오·과제·채점 답안)
app.js       상태·라우팅·화면 렌더·계산 엔진·채점 엔진
tests/flow_test.py   Playwright 로컬 검증(5단계 전체 클릭·계산·작성·채점·콘솔 에러)

```

## 로컬 검증

```bash
pip install playwright && playwright install chromium
LD_LIBRARY_PATH=/workspace/.libs/usr/lib/x86_64-linux-gnu python3 tests/flow_test.py
```

검증 항목: 홈 → 카드 4장 → 12포인트 방문 → 퀘스트 3/3 → 시뮬레이터(예열 10 °C · 두께 3–32 mm · 입열 1.25 kJ/mm · 비저수소 시 범주 A 65 °C · T=25 mm 무제한) → 시나리오 3/3 → 마법사 10단계(F-No. 자동 제안) → 제출 100점 합격 → 리뷰 → 사전 검색 → 강사 모드 → 인정범위 초과(45 mm) 입력 시 불합격·치명 오류 → 모바일 뷰 → 콘솔 에러 0건.

## 판본·수치 주의

- Table 5.8(예열)과 Table 6.2(두께) 값은 코드 병기값(°F/°C, in/mm)을 그대로 사용했습니다. 경계값(20/38/65 mm, 25 mm)은 판본 표기를 따릅니다.
- 이음상세 치수(개선각·루트 개구부)는 판본·공정별로 허용 조합이 다릅니다. 앱은 과제 값(45°, 6 mm)만 제시하고 상세 기호로 판정합니다.
- Table 6.6/6.8의 필수변수 항목은 요지를 요약한 것입니다. 항목별 정확한 조건은 원문을 확인하세요.
- 화면·문서의 회사명·프로젝트명·서명은 모두 가상이며, 사내 문서에서 온 값은 포함하지 않았습니다.
