# WPS작성 실습 — 철골 필렛 · AWS D1.1/D1.1M:2025

전화 한 통으로 시작되는 하루를 따라가며, **빈 WPS 한 장을 직접 채워 보는** 강의용 웹앱입니다.
서버·로그인이 없고, 모든 판정은 브라우저 안에서 끝납니다.
조항·표 번호와 영문 인용은 **AWS D1.1/D1.1M:2025 원문**을 대조했습니다(→ `docs/AWS_D1.1_2025_원문대조표.md`).

> ⚠️ **교육용입니다.** 인물·회사·도면·WPS 번호와 12 mm 등 시나리오 수치는 익명·가상입니다.
> 강종(ASTM A36)과 설계 값은 사전인정 필렛 WPS 작성 사례를 코드 조항과 대조해 옮겼습니다
> (→ `docs/AnnexJ_사전인정_검토메모.md`).
> 실제 제작·검사에는 계약에서 지정한 판본과 발주처 시방서를 적용하세요.

## 실습 설계 (v4)

- **「이 값 넣기」 버튼은 없습니다.** 수강생이 스스로 고르고 계산해 적습니다.
- **선택형** — 이음 형식·받침판·AWS Group·전극 극성·필러 분류·F-No./A-No.·차폐가스·자세·예열·PWHT·인정 방식은 칩 선택,
  모재 규격·인정 두께 범위·공정은 드롭다운입니다. 오답 선택지를 섞어 판단 연습을 하게 했습니다.
- **직접 입력형** — 루트 간격·필렛 각장·**예열 온도**·**입열량**과 와이어 지름·전류·전압은 수치를 직접 입력합니다.
  입열량 칸은 조건(29 V · 260 A · 300 mm/min)과 공식 `H = (60 × 전압 × 전류) ÷ (1000 × 용접속도)`만 보여 주고,
  정답을 대신 넣어 주지 않습니다.
- **와이어 지름 · 전류 · 전압**은 세 칸 모두 **비필수**이며 자유 입력입니다. 어떤 유효한 값이나 범위(예: `120-300`)를
  적어도 감점·오류 없이 통과합니다.
- **근거 팝오버** — 문항 카드/라벨을 누르면 열리고, **더블클릭(모바일 더블탭) 또는 × 버튼**으로 닫힙니다.
  입력·선택을 조작하는 동안에는 열리지 않습니다. 모바일(390×844)에서는 화면 높이 약 46 % 이하의
  컴팩트 시트로 열리고 내부 스크롤되며, 제출 바를 가리지 않습니다.

## 5차 마무리 (v5)

| # | 요청 | 반영 |
|---|---|---|
| 1 | 전류·전압 **최소~최대 두 칸** | `ui:'range'` — 왼쪽 `최소`, 오른쪽 `최대`. 비필수 유지, **한 칸만 적어도 합격**, 둘 다 적으면 `최대 ≥ 최소`만 확인. 범위 예시는 실제값을 가운데 두도록(`240 ~ 280`) 안내하고, 한 칸만 적으면 “실무 WPS는 범위로 적는다”는 노란 안내만 띄웁니다(감점 없음) |
| 2 | **와이어 지름 복수 입력** | `1.2` / `1.2, 1.4` / `1.2/1.4/1.6` / `1.2 1.4` 모두 인식(콤마 소수점 `1,2`도 처리). 1개·2~3개 모두 합격. 입력 즉시 `인식: Ø1.2 · Ø1.4` 표시 |
| 3 | **합격 후 경제성·적정 조건 카드** | 결과 화면 아래 `#wireEcon` — ① 교재 p.100 노즐 높이별 적정 유량표(내가 적은 지름 행 하이라이트) ② Stick-out(CTWD·리세스 구분 도식) ③ 교재 p.425 예제 2 단면적 비교(a 100 / b 50 / c 50 / d 57.8 mm²) SVG 도식 + 현장 적용·체크포인트 |
| 4 | **자막 표기 교정** | `SCENARIO.narr[key].cap`(화면 표기)과 `.text`(음성 발음용)를 분리. 자막은 `ASTM A36 · 12 mm · AWS D1.1/D1.1M:2025 · Table 5.6, Group I · E70T-1C · −3 °C`로 표기하고 **음성 파일은 그대로** 둡니다 |
| 5 | **배경음악** | 요청 곡(`youtu.be/mD4GbGmvNRc`)은 **StarCraft – Terran Theme 1**(Blizzard 저작물)입니다. 음원 추출·재배포는 저작권 침해이고 YouTube 약관에도 어긋나 public GitHub Pages에 올릴 수 없습니다. 그래서 곡의 **템포(≈96 BPM)·단조 진행(Em–C–G–D)·디스토션 파워코드·신스 브라스·금속 타격**만 분석해 **오리지널 트랙**(`audio/bgm_terran.mp3`, 40초 루프, 합성음만 사용)으로 새로 만들었습니다 |

> 경제성 카드는 **교재 예제**입니다. (b)~(d)는 순수 필릿이 아니라 베벨 그루브(PJP)+필릿이고, 이번 개소(개선 없는 6 mm 필릿)와는 이음 형식이 다릅니다. 카드 안에 그 단서와 “같은 목 두께·같은 공정·같은 자세에서만 성립”이라는 조건을 함께 적었습니다.

### 판단 설계의 핵심 (2025 원문)

- **A36은 Table 5.6 등재 강재**(Group I ≤20 mm / Group II 전 두께) → Clause 5 조건을 지키면
  **PQR 없이 사전인정**(Supporting PQR: None (Prequalified), Annex J J2). 조건을 하나라도 벗어나야 Clause 6 시험입니다.
- **루트 간격**: 7.21.1 — 최대 3/16 in(5 mm), **1/16 in(2 mm)를 넘으면 초과량만큼 각장 증가**.
  현장 실측 1.5 mm → 0~2 mm 관리 범위.
- **예열**: Table 5.11 — 저수소 공정 12 mm는 최소 0 °C이나, 모재가 0 °C 미만이면 **20 °C 예열·층간 유지**.
  내일 07시 −3 °C가 함정입니다.
- **필러**: Table 5.7 — E7XT-XC 등재. E70T-1C(아래보기·수평 전용) vs **E71T-1C(전자세·CO₂)**.
- **극성·가스·자세**: DCEP, 100 % CO₂ 15~30 L/min + 방풍(서풍 3~4 m/s), **All 자세 · 수직 상진**(5.8.1.1).
- **최소 각장**: Table 7.7 — 12 mm는 6 mm 구간이므로 도면 지시 6 mm가 최소치를 만족(7.13).
- **F-No./A-No.**는 ASME Sec. IX 용어. D1.1은 AWS 분류로 필러를 관리하므로 참고 기재/N/A.
- **입열량**은 충격시험(CVN)이 요구될 때만 재인증 대상인 **추가필수** 변수(Table 6.8). 이번 건은 CVN **No**.

### 채점

- 20칸 배점 합계 100점, **치명 오류 0건 + 80점 이상**이 합격.
- 치명 오류는 즉시 파단으로 이어지고, 파단 유형이 원인별로 달라집니다(수소 지연 균열 / 목두께 부족 /
  융합 불량 / 기공 / 감리 반려).
- 불합격 시 틀린 칸만 비우고 재도전합니다.

## 음성·음악

| 구분 | 파일 | 설명 |
|---|---|---|
| 배경음악 | `audio/bgm_terran.mp3` | 40초 인더스트리얼 루프(오리지널 작곡, BPM 96). `[시작 →]`에서 재생, 음성 재생 중 자동 덕킹(0.15 → 0.04). **저작권 안전** — 원곡 음원·샘플을 쓰지 않고 합성음(`tools/make_bgm.py`)으로만 만들었습니다 |
| 내레이션 | `audio/n_*.mp3` | 아나운서 톤(ko-KR-SunHiNeural) — 상황 안내·핵심 정리·결과·사고 원인·성공/파단 엔딩 |
| 효과음 | `audio/sfx_*.mp3` | 전화벨·수화기·성공 차임·파단 크랙·철골 붕괴 |

**인물 통화 음성(p00~p09 · s01~s03 · f01~f02)은 전부 제거했습니다.** 전화·브리핑·엔딩의 대화는
화면 자막과 말풍선으로만 진행되고, 소리는 효과음과 아나운서 내레이션이 맡습니다.
상단 바에서 **BGM**과 **소리**를 각각 켜고 끌 수 있습니다(설정 유지).

대본은 숫자·약어를 한국어 발음으로 적고(`WPS`→“더블유 피 에스”, `ASTM A36`→“에이에스티엠 에이 삼십육”),
`faster-whisper` small-int8(CPU 1스레드) 전사로 문장 일치율까지 확인했습니다(`docs/audio_transcript.json`).
**5차부터 화면 자막과 음성 대본을 분리**했습니다 — 음성은 발음용 문장(`narr.text`)을 그대로 쓰고, 자막은 화면 표기(`narr.cap`)로
`ASTM A36 · 12 mm · AWS D1.1/D1.1M:2025`처럼 읽기 쉽게 보여 줍니다.

## 접근성·환경

- 근거는 문항을 눌러 열고, `Esc`·더블클릭·×로 닫힙니다. `?` 버튼은 키보드 포커스로도 열립니다.
- `prefers-reduced-motion`에서는 애니메이션 길이를 최소화합니다.
- 소리는 상단 바에서 끌 수 있고, 끈 상태는 브라우저에 기억됩니다.
- 정적 파일만으로 동작하며, GitHub Pages에 그대로 배포됩니다.
