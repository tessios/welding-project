# WPS작성 실습 — 철골 필렛 · AWS D1.1

전화 한 통으로 시작되는 하루를 따라가며, **빈 WPS 한 장을 직접 채워 보는** 강의용 웹앱입니다.
서버·로그인이 없고, 모든 판정은 브라우저 안에서 끝납니다.

> ⚠️ **교육용입니다.** 화면의 WPS·도면·PQR 번호·서명은 모두 가상 문서이고, 수치는 판본 원문 대조 전 교육용 대표값입니다.
> 팝오버의 AWS 문구는 원문 인용이 아닌 **요약**이며, `(확인 필요)`로 표시된 조항·수치는 배포 전 D1.1/D1.1M 원문 대조가 필요합니다.
> 실제 제작·검사에는 계약에서 지정한 판본과 발주처 시방서를 적용하세요.

## 장면 흐름

| 장면 | 화면 | 내용 |
|---|---|---|
| 0 | 랜딩 | **WPS작성 실습** 표제 + `[시작 →]` (하단, 화살표 포함) |
| 1 | 전화 | 철골 현장 시공팀장이 이프로에게 전화 — “내일 보–브래킷 필렛, WPS가 없다”. `[지직—]`로 끊긴 세 가지(필러·예열·인정 방식)가 학습 과제가 됨. 이프로의 고민 독백으로 마무리 |
| 2 | 브리핑 | 보 웨브–브래킷 수직 필렛 단면도(6 mm·3F) + 재질 **SM275** / 두께 **12 mm** / 부위. **자료함**에 날씨(−3 °C·서풍 3~4 m/s), 사내 PQR 목록(PQR-ST-012), 장비·와이어 재고(함정 포함)를 숨겨 둠 |
| 3 | 작성 | **공백 WPS 18칸**. 마우스 오버·터치·키보드 포커스로 팝오버: 파란 점 = 현장 정보(「이 값 넣기」로 키인), 주황 점 = AWS D1.1 근거. ⭐는 감리가 먼저 보는 칸. 우측 **놓친 정보** 트레이가 채운 칸을 ✓로 표시 |
| 4 | 결과 | 합격 → 다음 날 전화(“이프로 덕분에 중요한 용접 잘 마무리했어. 역시 최고.”). 불합격 → **필렛부 파단 애니메이션** + 오류 항목·근거 + 재도전 |

### 판단 설계의 핵심

- **SM275는 Table 5.3에 없는 강재** → 사전인정(Clause 5) 불가. 자료함의 PQR-ST-012(SM275·25 mm·3G 상진)를 근거로 **Clause 6 시험인정**을 골라야 통과합니다.
- **예열**: 저수소 공정 20 mm 이하는 0 °C이지만, 내일 07시 −3 °C → **최소 20 °C**. “작년엔 그냥 했다”가 함정입니다.
- **필러**: E70T-1C(아래보기·수평 전용) vs **E71T-1C(전자세·CO₂)**. 재고에 있다고 맞는 와이어가 아닙니다.
- **극성·가스·자세**: DCEP, 100 % CO₂ + 방풍(바람 3~4 m/s), 3F 수직 상진.
- **F-No./A-No.**는 ASME Sec. IX 용어입니다. D1.1은 AWS 분류(Table 5.4)로 필러를 관리하므로 이 칸은 **참고 기재**로만 채웁니다.

### 채점

- 18칸 배점 합계 100점, **치명 오류 0건 + 80점 이상**이 합격.
- 치명 오류는 즉시 파단으로 이어지고, 파단 유형이 원인별로 달라집니다(수소 지연 균열 / 목두께 부족 / 융합 불량 / 기공 / 감리 반려).
- 불합격 시 틀린 칸만 비우고 재도전합니다.

## 파일

```
index.html   표지·장면 뼈대 (랜딩은 정적 HTML)
styles.css   근흑색 표면 · 헤어라인 레일 · 은색 액센트 · WPS 지면 스타일
data.js      대본 · 브리핑 · 18칸 정의(정답·근거·배점) · 파단 유형
app.js       화면 전환 · 전화 연출 · 팝오버 · 채점 · 단면 SVG(파단 애니메이션)
fonts/       Pretendard Variable (자체 호스팅, 오프라인에서도 동일 서체)
tests/       Playwright 전 구간 클릭 테스트 · 입력/트레이 테스트
screenshots/ 검증 화면 캡처(로컬 산출물, 저장소에는 올리지 않음)
```

## 로컬 검증

```bash
pip install playwright && playwright install chromium
LD_LIBRARY_PATH=/workspace/.libs/usr/lib/x86_64-linux-gnu python3 tests/flow_test.py
```

검증 항목: 랜딩 → 전화(수신·통화·독백) → 브리핑(자료함 펼침) → 공백 WPS(호버 팝오버 2종) → 18칸 입력 → 제출 100점 합격 → 오답 제출 시 파단 연출·오류 카드 → 모바일(390×844) 뷰·바텀시트 팝오버 → 콘솔 에러 0건.

## 접근성·환경

- 모든 팝오버는 마우스 오버, 탭, 키보드 포커스로 열리고 `Esc`로 닫힙니다. 모바일에서는 하단 시트로 뜹니다.

- 소리 없이 진행됩니다(자막·시각 효과로 대체).
- 정적 파일만으로 동작하며, GitHub Pages에 그대로 배포됩니다.
